Tool 接口与执行架构总览

interface Tool src/tools/types.ts:291
  • name — 工具名（硬编码字符串，防压缩混淆）
  • description — 面向模型的英文描述
  • category — read | write | command，决定权限矩阵与默认并发策略
  • deferred? — 延迟加载（仅 MCP 包装器为 true，须先经 ToolSearch 发现）
  • isConcurrencySafe?(args) — 按实际参数判断本次调用可否并发；未实现时按 category 回退
  • schema() — 返回 ToolSchema（input_schema / description）
  • execute(ctx, args) — 执行并返回 ToolResult
  • dispose?() — 释放会话级资源（如 Bash 的沙箱）
ToolResult / ToolContext
  • output — 文本结果（必有）
  • contentBlocks? — 图像 / 文档 / search_result 等富内容块
  • mcpApp? — MCP 内联应用（create_app）
  • isError — 是否作为错误回传给模型
  • Context 注入：cwd · abortSignal · taskManager · permissionChecker · onPermissionRequest · fileStateCache · fileHistory · goalManager · sessionId · onOutput 等
沙箱与权限分层 src/permissions · src/sandbox
  • 🛡️ OS 沙箱：仅包裹 Bash — macOS seatbelt（/usr/bin/sandbox-exec）/ Linux bubblewrap；配置 sandbox.enabled · auto_allow · network_enabled；含 allowWrite / denyWrite 白黑名单
  • 📁 PathSandbox：权限层对 write 类工具做路径校验（项目根 + tmpdir + extraRoots 之外 → 询问）
  • ⚖️ 决策层：显式规则 → 计划文件豁免 → 安全命令放行 → 危险命令拦截 → 沙箱 auto-allow（仅 Bash）→ 写路径校验 → 规则引擎 → 模式矩阵

注册入口 createToolRegistry()（src/bootstrap/tool-registry.ts）：交互模式注册 TaskCreate/Get/List/Update 四件套，非交互模式注册 TodoWrite；带 teamManager 时以 TeamTask*（继承 Task*，共享任务板）替换。 MCP 服务器工具经 MCPToolWrapper（implements MCPToolLike extends Tool）动态包装，是唯一 deferred=true 的工具形态；ToolSearch/McpCall 仅在 native/dispatch 加载模式下暴露。
